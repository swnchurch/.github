# # South Weymouth Church of the Nazarene

This is the GitHub home of the technology team at **South Weymouth Church of the Nazarene** (SWN) in South Weymouth, Massachusetts.

We keep the church's own software here, so that it belongs to the church and not to any one volunteer or vendor. Every change is recorded, and the work can be picked up by whoever serves next.

## What's here

| Project | What it is |
|---|---|
| **SWN Stewardship** | The church's budget and spending app: ministry budgets, approvals, check requests and reports. (Private) |
